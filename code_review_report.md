## Issues Found & Fixes Applied

### 1. `data_prep.py` — KeyError on 5 Missing CWE Templates 🔴 **MAJOR**
**Lines:** 42–105  
**Problem:** `_generate_demo_data()` iterates `config.TARGET_CWE` (10 types: CWE89, CWE798, CWE121, CWE122, CWE401, **CWE22, CWE78, CWE79, CWE476, CWE416**), but `_VULN_TEMPLATES` and `_SAFE_TEMPLATES` only defined the first 5. Would crash with `KeyError: 'CWE22'` any time the Juliet dataset was absent and the synthetic fallback triggered.  
**Fix:** Added all 5 missing templates to both dicts with realistic vulnerable/safe C code patterns.

### 2. `app.py` — CUDA autocast crash on CPU 🔴 **MAJOR**
**Line:** 184  
**Problem:** `with torch.amp.autocast('cuda'):` was called unconditionally during model inference. On a CPU-only machine (local dev, CI, CPU-tier Kaggle) this raises `RuntimeError: Expected a CUDA device`.  
**Fix:** Gated autocast inside `if config.DEVICE == "cuda":` with a plain inference `else:` branch.

### 3. `modules/fusion.py` — Hard crash on missing `fuzzy_risk_score` ⚠️ **MINOR**
**Line:** 189  
**Problem:** `fuse_features()` raised a bare `KeyError` if `fuzzy_risk_score` was absent. The merged dataset from `download_bigvul.merge_datasets()` could lack this column if bigvul hadn't been scored.  
**Fix:** Replaced `raise KeyError` with `logger.warning` + `np.full(n, 0.5)` fallback so fusion proceeds without crashing.

### 4. `finetune_codebert.py` — `GradScaler()` deprecation ⚠️ **MINOR**
**Line:** 136  
**Problem:** `torch.amp.GradScaler()` called without device argument. PyTorch ≥ 2.3 emits a deprecation warning; future versions may require it.  
**Fix:** Changed to `torch.amp.GradScaler("cuda")`.

### 5. `download_devign.py` — Hardcoded Windows path in error message ⚠️ **MINOR**
**Line:** 53  
**Problem:** Error message contained `D:\\pytorch_env\\Scripts\\pip install datasets` — would confuse Kaggle users or anyone without that exact virtualenv path.  
**Fix:** Changed to `pip install datasets`.

### 6. `evaluate.py` — `torch.load()` missing `weights_only=True` ⚠️ **MINOR**
**Line:** 126  
**Problem:** PyTorch ≥ 2.0 warns about `torch.load()` without `weights_only=True` due to pickle security risk.  
**Fix:** Added `weights_only=True`.
